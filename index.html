04How the Analysis Works
A simple process showing how the DNA sequence is analyzed and represented.

  

    
STEP 01
Validate
The program cleans the input and checks that every character belongs to the four DNA bases: A, T, C or G.

    
STEP 02
Encode
Each base is assigned a 2-bit binary value using the selected mapping, giving every sequence a digital representation.

    
STEP 03
Visualize
The bases are rendered as colored blocks. Similar sequences tend to produce similar visual patterns.

    
STEP 04
Compare
Verification uses a simple Hamming-distance comparison against the built-in reference sequences.

    
STEP 05
Measure
The simulator calculates length, binary size, GC content and sequence entropy for quick analysis.

    
STEP 06
Advanced Genetic Insights
Explore deeper sequence patterns, genetic relationships, variation signals and biodiversity insights from the analyzed DNA.
